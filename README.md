# TO-Do List

A simple and user-friendly To-Do List Management System developed using Python and Tkinter. This application helps users organize their daily tasks, manage priorities, set due dates, and track their task completion progress.

# Features:

Add new tasks with priority and due date.
View all saved tasks.
Search tasks by name.
Edit and delete tasks.
Mark tasks as completed or pending.
Track task progress and statistics.
Save tasks automatically using JSON.

# Technologies Used:

Python
Tkinter
ttk – Enhanced GUI widgets
JSON – Data storage
DateTime – Date validation and management

# Project Objective:

The main objective of this project is to develop a simple desktop-based task management application that helps users organize their daily activities and improve productivity.

This project also demonstrates practical implementation of Python programming concepts such as:
Object-Oriented Programming (OOP)
GUI Development
File Handling
JSON Data Management
CRUD Operations (Create, Read, Update, Delete)
Event Handling
